Cloudflare Pages & Render Setup

  1. Deploy Backend to Render.com

    Push your repository to GitHub, link to Render.com as a Web Service (using Docker). Copy your backend URL (e.g. https://youtube-live-backend.onrender.com).

  2. Connect Backend URL

    Paste your Render backend URL into the Render Backend URL field at the top of this web app and click Save & Connect.

  3. Get YouTube Stream Key

    Go to YouTube Studio > Create > Go Live, copy your Stream Key.

  4. Upload & Stream

    Upload your video (up to 2GB), select Continuous Loop or Single Play, and hit START YOUTUBE LIVE STREAM!
